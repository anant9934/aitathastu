# Ecosystem entry points

The workspace links only to routes implemented in Core: student roadmap, projects, profile, connections, and the protected faculty verification queue. Learning, career, project, people, collaboration and research cards each expose a relevant Core destination when one exists.

Learn, ERIS, Meet, and Collaborate are not presented as connected live products from this workspace until their actual routes, authentication boundaries, and data contracts are verified. Cards never pass sensitive context through URL query strings. Empty opportunity and faculty integration states say what is unavailable.
