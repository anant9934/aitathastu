## 1. Principle
We keep information only as long as appropriate for documented service operations and applicable legal or security obligations. A file being stored for technical processing does not mean it is permanently part of a confirmed student profile. We do not guarantee instant removal from logs, backups or independent third-party systems.

## 3. User controls
A user can use supported controls to delete a CV, edit accepted claims, disconnect sources, request correction or close an account. These actions have different scope and may not automatically erase all derived or independently verified records. See [Your Rights](/privacy/your-rights).

## 4. Exceptions
Some records may need to be preserved for legal, security, contractual or dispute-resolution purposes with access restrictions. The current DPDP Rules and commencement dates must be evaluated by counsel for log/data retention and erasure obligations; these are not an instruction to preserve full resumes for any general fixed number of years.
