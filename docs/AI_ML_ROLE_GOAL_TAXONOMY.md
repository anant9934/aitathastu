# AI Tathastu — AI/ML Role & Goal Taxonomy

## 1. Overview
The AI Tathastu ecosystem is strictly dedicated to Artificial Intelligence and Machine Learning disciplines. The taxonomy defines 14 standardized AI/ML career directions, prerequisite competency matrices, and student outcome goals.

---

## 2. Canonical AI/ML Roles

### Engineering Category
1. **Generative AI Engineer** (`genai_engineer`)
   - *Core Prerequisites*: Python, Transformers, Vector Databases, Prompt Engineering
   - *Recommended Technologies*: LangChain, LlamaIndex, FAISS, PyTorch, FastAPI
2. **Machine Learning Engineer** (`ml_engineer`)
   - *Core Prerequisites*: Python, Scikit-Learn, Linear Algebra, Data Structures
   - *Recommended Technologies*: NumPy, Pandas, Scikit-Learn, XGBoost, PyTorch
3. **AI Engineer** (`ai_engineer`)
   - *Core Prerequisites*: Python, REST APIs, SQL, Cloud Basics
   - *Recommended Technologies*: FastAPI, Docker, PostgreSQL, OpenAI API, LangChain
4. **Deep Learning Engineer** (`deep_learning_engineer`)
   - *Core Prerequisites*: PyTorch, Calculus, Linear Algebra, GPU Computing
   - *Recommended Technologies*: PyTorch, TensorFlow, CUDA, Weights & Biases, ONNX
5. **MLOps Engineer** (`mlops_engineer`)
   - *Core Prerequisites*: Docker, Kubernetes, CI/CD, Python, Model Serving
   - *Recommended Technologies*: MLflow, Kubeflow, Docker, FastAPI, Prometheus
6. **NLP Engineer** (`nlp_engineer`)
   - *Core Prerequisites*: Python, Linguistics Basics, Transformers, Tokenization
   - *Recommended Technologies*: Hugging Face, spaCy, NLTK, PyTorch, LangChain
7. **Computer Vision Engineer** (`computer_vision_engineer`)
   - *Core Prerequisites*: Python, OpenCV, CNNs, Image Processing
   - *Recommended Technologies*: OpenCV, PyTorch, Albumentations, YOLO, TorchVision
8. **AI Infrastructure Engineer** (`ai_infra_engineer`)
   - *Core Prerequisites*: Linux, Distributed Systems, GPU Clusters, Networking
   - *Recommended Technologies*: Ray, SLURM, Triton Inference Server, CUDA, Kubernetes

### Research & Specialized Category
9. **AI Researcher** (`ai_researcher`)
   - *Core Prerequisites*: Mathematical Analysis, Literature Review, Experimental Design, PyTorch
   - *Recommended Technologies*: PyTorch, JAX, Weights & Biases, LaTeX, ArXiv
10. **Applied AI Researcher** (`applied_ai_researcher`)
    - *Core Prerequisites*: SOTA Benchmarking, Ablation Studies, Python, PyTorch
    - *Recommended Technologies*: PyTorch, Hugging Face, Weights & Biases, Scipy
11. **Reinforcement Learning Engineer** (`rl_engineer`)
    - *Core Prerequisites*: Markov Decision Processes, Dynamic Programming, PyTorch, Simulation
    - *Recommended Technologies*: Gymnasium, Stable-Baselines3, Ray RLLib, MuJoCo, PyTorch
12. **Robotics & AI Engineer** (`robotics_ai_engineer`)
    - *Core Prerequisites*: ROS2, Control Theory, Sensor Fusion, C++/Python
    - *Recommended Technologies*: ROS2, Gazebo, PyTorch, OpenCV, MoveIt

### Data & Product Category
13. **AI/ML Data Scientist** (`aiml_data_scientist`)
    - *Core Prerequisites*: Advanced Statistics, EDA, Feature Engineering, Python/SQL
    - *Recommended Technologies*: Pandas, Polars, Statsmodels, Scikit-Learn, Seaborn
14. **AI Product Builder / Founder** (`ai_product_builder`)
    - *Core Prerequisites*: Full-Stack AI, Product Analytics, Rapid Prototyping, Evaluation
    - *Recommended Technologies*: Next.js, FastAPI, PostgreSQL, LangChain, Vercel

### Exploration
- **Still Exploring AI & ML** (`still_exploring_aiml`)
  - *Core Prerequisites*: Python Fundamentals, Mathematics for ML, Data Exploration

5. Improve my AI/ML knowledge
6. Find AI/ML mentors or collaborators
7. Build an AI-powered product

## 4. Architectural Boundaries
- Selecting a target role expresses user intent; it does not grant institutional verification.
- Goal statements are persisted in the canonical `goals` table with provenance and audit timestamps.
