# Archived reports

These certification, verification and release reports were written **before**
the full codebase audit of 2026-10-12 (`docs/audits/FULL_CODEBASE_AUDIT_2026-10-12.md`)
and the fix pass that followed it.

Several of them mark flows as PASS that the audit later found broken. Examples:
CV OCR on serverless, false "saved" success after review, deselected CV
suggestions still being imported, cross-user document id collisions, and GitHub
usernames shown as "connected". Treat them as historical context only, not as
evidence of current behaviour.

For the current system see `docs/ARCHITECTURE.md` and `docs/DEPLOYMENT.md`.
