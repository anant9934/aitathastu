# Student dashboard priority compositions

The first ranked purpose occupies the largest first card and sets the hero. Secondary follows as a standard card. Tertiary is smaller by default. Pinning and explicit order can override the default. The student's specific goal is displayed separately from broad purpose.

| Primary purpose | First card | Actual source | Available next step |
|---|---|---|---|
| Learn AI & ML | Learning path | Recommended learning in student composition | Roadmap |
| Internships & Jobs | Opportunities | Authenticated internship records | Profile |
| People & Mentors | People | Authenticated mentor records | Connections |
| Collaborate | Shared work | Authenticated collaboration records | Projects |
| Build Projects | Projects | Confirmed project records | Projects |
| Research & Events | Research | Publication records | Roadmap |

An empty source displays a clear empty state. Purpose selection alone never produces a fabricated opening, mentor, publication, score, or event. Existing student detail pages remain available through navigation.
