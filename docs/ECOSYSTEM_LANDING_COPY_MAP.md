# Ecosystem landing page copy map

The user supplied HTML is the visual reference. This map records the principal wording changes while its section order, cards, orb, chart, and motion remain the design baseline.

| Reference message | Landing message | Reason |
| --- | --- | --- |
| “AI-native learning companion” and “Learn deeper. Build real things. Get discovered.” | “One ecosystem. Endless possibilities.” and “You imagine. AI makes it happen.” | Introduce the full product family through the approved brand line. |
| Three animated platform totals | Learn, Connect, Create value indicators | Remove unverified public counts. |
| EORA claims to have read visitor data | Public scripted suggestions and an illustrative conversation | Avoid implying account access or a live AI call on the public page. |
| Verified evidence, Person 360, skill graph ticker | Learn, Collaborate, Meet, ERIS, EORA ticker | Show ecosystem breadth immediately. |
| “From curiosity to achievement” with skill analysis stages | Discover, Learn, Build, Connect, Prove, Grow | Describe an understandable path without promising a rigid workflow. |
| Personalized sample dashboard and numerical scores | Clearly labeled example dashboard with Learn, Skills, Collaborate, Progress tabs | Preserve the preview design without presenting invented visitor data. |
| Seven capabilities as one live platform | Six named products with availability labels | Distinguish AI Tathastu Core and EORA from independent products in development. |
| Automatic footprint ingestion and universal verification | Chosen sources and reviewed evidence | Match the available Core workflow and consent boundary. |
| Four mandatory integration steps | Goal, direction, tools, journey | Make independent product use clear. |
| Automatically generated 14-week plan | Illustrative five-milestone journey | Remove a fabricated public promise. |
| Named mentors, member counts, match scores, active jobs | Example project, people, and career directions | Remove invented social proof and listings. |
| Automatic ecosystem links and strong privacy absolutes | Conceptual links and user-authorized connections | Avoid implying independent products exchange private records automatically. |
| “Free to start · No credit card required” and placeholder links | Signup and section anchors that exist | Remove unverified signup claims and ensure every visible action leads somewhere valid. |

## Product availability audit

The repository contains working `/sign-up`, `/sign-in`, `/student`, `/student/skills`, `/student/projects`, `/student/roadmap`, and EORA API routes for Core. Learn, Collaborate, and Meet have no independent public pages in this repository. ERIS has an integration endpoint but no public ERIS product route. The landing page therefore labels those four as **In development** and uses section anchors for exploration rather than invented product destinations. The public EORA demonstration does not call the authenticated EORA API.

The supplied attachments contained HTML and a written brief. No separate screenshot files were attached to this task, so visual comparison uses the HTML rendered in a browser as the reference.
